# Quality Reference Bar — Career Quest Campus

This folder is the committed quality bar for the Wow Quality Pass
(`docs/plans/2026-06-11-001-feat-wow-quality-pass-plan.md`, requirement R2).
It is the standing review anchor for all future visual work: every visual
milestone is judged side-by-side against these captures, not against memory
or taste in the moment.

## How the gate works

- **U1 checkpoint:** the owner affirms `building-direction-sample.png` as the
  direction for upgraded campus-building art before any world assembly (U4).
- **U9 flagship checkpoint (AE1):** screenshots of the campus walk, Design
  Build drag session, and reveal cinematic are composited beside these
  references. The gate question is genre membership: *"Does our screen read
  as the same genre of environment as these?"* — not pixel parity.
- **U14 final sweep:** the full screen set is composited against this folder
  one last time before the SubmissionBundle.

## Reference titles

| Capture | Title | Why it is the bar |
|---------|-------|-------------------|
| `toca-boca-world-screenshot-*.png` | Toca Boca World (Google Play store captures) | The bar for flat-color toy-diorama environments, prop density, and drag-tray direct manipulation — screenshot 2 shows the exact piece-tray drag pattern U6 builds. |
| `khan-academy-kids-screenshot-*.png` | Khan Academy Kids (Google Play store captures) | The bar for character-led joyful learning UI: soft shapes, generous type, character presence on every screen. |
| `skillsville-keyart.png` | Skillsville (PBS KIDS press art) | The bar for career-exploration framing: a virtual city of careers, badges, and kid heroes — Career Quest's closest premise sibling. |

## Kenney pack previews (`kenney-previews/`)

Icons, Emotes, Cursor Pack. These show the palette and shape language the
campus must stay coherent with.

## Building direction sample

`building-direction-sample.png` + `building-direction-sample.md` — the
owner-checkpoint artifact for upgraded owned campus-building art styled to
the Kenney palette (Kenney has no 2D cartoon town buildings, so campus
structures are owned art; everything else is Kenney). See the sample doc for
the spec.
