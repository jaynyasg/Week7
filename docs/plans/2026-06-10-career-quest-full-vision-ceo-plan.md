## Vision

### 10x Check
Kids don't open a career app — they graduate from a toy campus. Every room completion adds a skyline piece, a badge stamp, guide cheer, ambient life, and synced celebration with a friend on the same couch. Gallery feels like a passport book filling up; Career Reveal is a stage curtain moment with strength cards and co-lead ties highlighted. Evaluators see Play and Showcase parity: walkable hub, three tactile activity rooms on one architecture, visual-first proof, Windows build.

### Platonic Ideal (held as north star, not all in one week)
A handmade diorama campus where two kids explore together, NPCs react, props are draggable tools, every career room teaches through objects before text, multiplayer syncs gently host-authoritative, and the reveal ceremony feels like a school talent show — safe, celebratory, never judgmental.

```
CareerQuestApp
├── GameSession ─────────────► local mirror: CareerDna, reveal gate, best results, route
├── CampusSessionState (host) ► Netcode authority; snapshots → GameSession on clients
├── SceneFlowRouter ─────────► Entry → Avatar → Campus → Room → Gallery → Reveal
├── NetworkBootstrap / Netcode ► host-authoritative sync (Q8, mp sync A)
├── PlayableHubController ───► walk input, building triggers, camera follow
├── CampusWorldController ───► thin orchestrator (**LOCKED: A — layered presentation stack**)
│   ├── CampusParallaxController      (Q0E parallax C)
│   ├── CampusAmbientController       (exp1 living campus + exp2 SFX hooks)
│   ├── HubAvatarPresenter            (Q7 sprite sheets, Q8 2P poses)
│   └── CampusEvolutionController     (exp6 prop.city_piece_*)
├── ActivityRoomController* ─► DesignBuild / HealthHero / LogicCourt (Q10 migrate)
├── CeremonyController stack ► FeedbackController + AudioCueCatalog (planned)
├── Gallery / Reveal / Showcase presenters (exp4)
└── UI Canvas (Hud cards; action bar hidden in Play)

* Today: room controllers are MonoBehaviours, not yet subclasses — migration required.
```

```
    → GameSession.RecordResult → CareerDna.Recompute → Changed event
    → Ceremony stack (stamp/confetti/NPC) → Hub return → evolution piece (exp6)
```

## Section 2 — Error & Rescue Map (COMPLETE)

### Error paths (target codepaths)

| Codepath | What can go wrong | Rescued today? |
|----------|-------------------|----------------|
| `NetworkBootstrap` connect | Host/client start fails | Y — `StartSoloFallback` at connect time |
| Netcode mid-session disconnect | P2/host drops during hub/room/ceremony | **N ← GAP** |
| `ActivityResultEmitter.Emit` | Null session/state/result | Y — rejects, no double emit |
| `GameSession.RecordResult` | Invalid/null result | Y — guarded |
| `CeremonyController` sequence | Interrupted (disconnect, route change, double complete) | **N ← GAP** (stack not built) |
| `AssetCatalog` full batch (0E-D) | Missing PNG after import | Partial — `SpriteFallbackFactory` + `PlayerFacingFallbackUsage()` report |
| `SceneFlowRouter` during ceremony | Hub/gallery transition before ceremony ends | **N ← GAP** until `ActivityPhase.Ceremony` gate (S1-A) |

| Issue | Decision |
